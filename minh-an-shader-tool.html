02 · Thay màu trong file văn bản

Chỉ hỗ trợ thay thế mã màu dạng HEX trong file văn bản như .shader, .txt, .json hoặc .mat đã xuất dạng văn bản. Không thể sửa trực tiếp gói nhị phân UnityFS/.bundle bằng thay chuỗi.

Lưu ý: Nếu file báo UnityFS hoặc dữ liệu nhị phân, công cụ sẽ không thay đổi nội dung vì thay byte tùy tiện có thể làm hỏng bundle. Hãy dùng bản sao và định dạng xuất/nhập chính thức của công cụ bạn được phép sử dụng. Công cụ không sửa game đang chạy, không tạo X-ray hay vượt cơ chế chống gian lận.
